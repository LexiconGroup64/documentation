# Chats as learning tools
During the course, AI can function as a great assistant for one's learning. Ask it for additional exercises, quizzes and more. This is not so much a side project for this week, but a tool for the rest of the course. 

## Let generative AI make exercises
Ask AI for versions of an exercise. Make the version in a different domain, a bit harder or easier or maybe give a partial solution to get you going.

## Flashcards
Cards with a single word to flip through in order to give you a chance to explain the concept or multiple-choice alternatives can be a quick way to rehearse a lecture subject. You could also test yourself on code snippets. 

## What Claude proposes as other options
The following generated list give a few other ideas. Don't deep read the example prompt for what it's actually saying, but get a general idea of what a prompt could be. 

| Option | What the AI does | Example prompt |
|---|---|---|
| Explain it another way | Re-explains a concept through an analogy, a simpler level or a different angle | "Explain async/await using a restaurant kitchen analogy." |
| Socratic tutor | Asks guiding questions instead of giving the answer | "I'm stuck on this exercise. Don't solve it — ask me questions that lead me forward." |
| Find-the-bug exercises | Writes code with planted bugs for you to find and fix | "Write a C# class with three subtle bugs a beginner might make. Don't reveal them." |
| Code review | Reviews your solution for readability, naming and structure | "Review my solution as a senior developer would. Point out issues but don't rewrite it." |
| Read and predict | Gives code to trace by hand before running it | "Give me a short JavaScript snippet with closures and ask what it logs." |
| Test-first exercises | Writes unit tests you must make pass | "Write xUnit tests for a ShoppingCart class. I will write the implementation." |
| Cheat sheets and summaries | Condenses a topic into a one-page reference | "Make a one-page cheat sheet of the Git commands we used this week." |
| Concept maps | Shows how concepts relate to each other | "Show how controller, service, repository and DbContext relate in an ASP.NET app."
| Mini projects | Combines several weeks' topics into one small project brief | "Write a project brief that combines a REST API, EF Core and a React frontend." |
| Interview practice | technical interview questions and gives feedback on answers | "Act as an interviewer for a junior .NET role. Ask one question at a time." |
| Explain your own code | Asks you to explain your code, then checks the explanation | "Here is my code. Ask me to explain what each part does, then tell me what I missed." |
